# GG-Anti-Popup
Removes "subscribe yearly" popup in GeoGuessr

Step 1: Install [Tampermonkey](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)

Step 2: Enable Developer Mode in browser extension settings

Step 3: Install the [userscript](https://github.com/SillyMeowerCat/GG-Anti-Popup/raw/refs/heads/main/script.user.js)

Step 4: Enable Extension & Restart your browser

Step 5: Enjoy.
